# Improve the ABM BPO corporate website

## Goal
Update the English website to faithfully present the expanded academic project, use MONTOC as the anchor client, and restore the original blue-and-purple brand identity.

## Changes
- Replace all LushGlow references with MONTOC and update the case-study copy around its beauty tools, makeup, and skincare business.
- Restore a cohesive navy, electric blue, and purple palette across the logo, backgrounds, accents, buttons, charts, and interactive states.
- Correct the project metrics to match the document: 35% cost reduction, 80/20 SLA, 5:30 AHT, 80% FCR, 4.2/5 CSAT, 200 new customers, 12% conversion, COP 250M sales, COP 150M collections, and 300 recovered accounts.
- Add concise, polished sections for the expanded project: market opportunity, 2026 SMART objectives, campaign operations and staffing, quality assurance, compliance, financial model, continuity plan, and leadership team.
- Improve navigation and section order so the longer content remains easy to scan on desktop and mobile.
- Keep the existing contact and PQR interactions, updating their references and styling to match MONTOC and the restored palette.
- Add page-specific English metadata and verify the final page visually on desktop and mobile.

## Technical details
- Keep the current single-page TanStack layout and reusable UI controls.
- Use semantic design tokens in the global stylesheet rather than hardcoded page colors.
- Use expandable/tabbed summaries for detailed academic information instead of placing the full 43-page report verbatim on screen.
