# Add BPO flow charts

## Goal
Add clear, interactive flow charts for MONTOC Customer Service and Sales & Marketing, distinct from the existing process-route diagrams.

## Changes
- Add a dedicated flow-chart section after Process Routes with tabs for both services.
- Show start/end ovals, activity rectangles, decision diamonds, directional arrows, responsible roles, and labeled Yes/No branches.
- Model realistic WhatsApp Business paths: inquiry/request/claim handling for Customer Service, and qualification/purchase/follow-up for Sales & Marketing.
- Include a compact symbol legend and keep the existing blue-and-purple visual identity.
- Add direct navigation to the new flow charts and verify desktop and mobile layouts.

## Technical details
- Build the diagrams as responsive React/CSS layouts so labels remain readable and accessible.
- Reuse existing semantic design tokens and current single-page navigation patterns.
